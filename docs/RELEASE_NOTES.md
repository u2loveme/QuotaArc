# QuotaArc 0.9.0 — Public Beta

QuotaArc 0.9.0 is the first public beta of the Windows desktop dashboard for
Codex quota and locally observed token usage.

## Included

- Live 5-hour and weekly quota status with reset timing and quota history.
- Reserve quota display when Codex provides that data.
- Daily observed token usage with input, cached, output, and reasoning
  breakdowns.
- Compact Mini panel, Windows tray controls, and configurable quota alerts.
- Self-contained Windows x64 ZIP package with install and uninstall scripts,
  first-run local database initialization, and legacy profile migration.
- Local-first usage history and preferences.

The app requires a discoverable, authenticated Codex CLI for live quota data.
It can be installed without Codex; in that case live quota is unavailable.

This beta is unsigned. Windows may display a SmartScreen or unknown publisher
warning. Verify the published checksum and download only from the official
release page. Never disable Windows security to install it.
